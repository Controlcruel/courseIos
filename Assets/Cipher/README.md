# Cipher — AR-детектив для iPhone

Игрок наводит iPhone на свою комнату. Игра находит в ней столы, стены и пол и раскладывает
по ним улики кибератаки. Улику нужно найти, подойти ближе и удерживать палец на экране —
тогда откроются сведения. Некоторые следы (отпечаток пальца) видны только через УФ-фильтр.
Когда все улики собраны, на доске расследования нужно восстановить порядок атаки,
после чего на стене комнаты открывается портал в будущее.

## Как устроен проект
- `Data/Case_NovaSoft.asset` — **«Дело»**: весь сюжет (брифинг, тексты доски, финал) и список улик. Редактируется в Inspector.
- `Prefabs/Clues/` — **улики**. У каждой на корне компонент **Cipher Clue**: название, сведения, урок,
  поверхность (стол/стена/пол), видна ли только в УФ, номер шага атаки. Внешний вид — дочерний объект `Model`.
- `Scenes/Cipher.unity` — сцена. Объект **Cipher UI** — экранный интерфейс (кнопки и панели можно двигать и перекрашивать).
- `Scripts/` — код игры, `Editor/` — пункты меню **Cipher**, `Resources/` — шейдеры, `Fonts/` — шрифты с кириллицей.

## Как добавить свою улику
1. Перетащите любой префаб из `Prefabs/Clues` в сцену и распакуйте его копию (или создайте пустой объект).
2. Внутри объекта `Model` замените кубики своей 3D-моделью. Модель должна «лежать на столе»: ось Y — вверх от поверхности.
3. На корне в компоненте **Cipher Clue** заполните тексты и настройки.
4. Перетащите объект в папку `Prefabs/Clues` — получится новый префаб. Удалите его из сцены.
5. Откройте `Data/Case_NovaSoft.asset` и добавьте префаб в список **Clues**.

## Меню Cipher
- **Собрать всё** — настроить проект, создать ресурсы и сцену за один раз.
- **1. Настроить проект для iPhone** — Bundle ID, iOS 15+, вертикальная ориентация, описание камеры.
- **2. Создать ресурсы и улики** — создаёт только то, чего ещё нет (ваши правки не трогает).
- **3. Создать сцену игры** — пересоздаёт сцену `Cipher.unity` (ручные изменения в сцене пропадут!).

## Проверка в редакторе (XR Simulation)
Play → виртуальная комната. **ПКМ + WASD** — ходить, **ЛКМ** — касание (удерживать — сканировать).
Клавиши для отладки: **U** — УФ-фильтр, **C** — сразу открыть следующую улику.
